## 3. Detailed Findings
### [CONCURRENCY]
#### Finding #`1`
Severity: `High`  
File: `src/Emcode.Pst.Libs/Infrastructure/Ndb/NdbBlockWriter.cs`  
Line: `93`  
Issue: Operasi `Seek` dan `Write` pada stream dilakukan tanpa sinkronisasi.  
Technical Explanation: Posisi stream adalah shared mutable state; eksekusi paralel bisa menimpa offset tulis antar block.  
Impact: Korupsi data block PST.  
Risk If Ignored: Integritas file PST tidak terjamin pada concurrent write.  
Recommendation: Tambahkan sinkronisasi I/O write block.  
Suggested Refactor Code:
```csharp
private readonly object _ioSync = new();
lock (_ioSync)
{
    _stream.Seek((long)allocation.Ib, SeekOrigin.Begin);
    _stream.Write(buffer);
}
```

#### Finding #`2`
Severity: `High`  
File: `src/Emcode.Pst.Libs/Infrastructure/Ndb/PstNdbWriter.cs`  
Line: `69`  
Issue: Koleksi mutable (`_tableRowCache` dan state writer lain) dimutasi tanpa kontrak thread-safety.  
Technical Explanation: Operasi create/update table dan cache row-id tidak dilindungi gate sinkronisasi.  
Impact: Snapshot NBT/BBT dan cache dapat tidak konsisten.  
Risk If Ignored: Potensi inkonsistensi struktur tree saat penggunaan paralel.  
Recommendation: Terapkan synchronization boundary pada operasi write publik.  
Suggested Refactor Code:
```csharp
private readonly SemaphoreSlim _gate = new(1, 1);
await _gate.WaitAsync(cancellationToken);
try { /* critical section */ }
finally { _gate.Release(); }
```
